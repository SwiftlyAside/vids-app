vids

vids is a private, single-operator tool used to manage the operator's own YouTube channels. It runs only on the operator's computer and is not offered to the public.

It uses the YouTube Data API and YouTube Analytics API to:

  • read channel and video information of the operator's own channels,
  • read analytics reports for those channels,
  • upload videos to those channels as private.

vids uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service.
